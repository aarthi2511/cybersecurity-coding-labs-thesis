\\# Cybersecurity Coding Labs — Master's Thesis







Design and Evaluation of Practical Cybersecurity Coding Labs for Software Engineering Education







\\## Structure







Each lab folder contains two subfolders:



\\- `reference\\\_solution/` — complete working implementation (instructor use)



\\- `student/` — stub version with TODO markers (student use)







| Folder | Lab | Description |



|---|---|---|



| Intrusion\\\_detection | Lab 1 | Network intrusion detection from authentication logs |



| Password\\\_analyzer | Lab 2 | Password strength analysis using the RockYou breach corpus |



| Phishing\\\_detection | Lab 3 | Rule-based email phishing detection |



| phishing\\\_ml | Lab 3.0 | Machine learning extension of Lab 3 |







\\## Setup







See Section 4.7 of the thesis for full installation instructions, including



Python/package requirements and Kaggle API setup (needed for Lab 2 and Lab 3.0).







\\## Note on datasets







Datasets are not included in this repository due to size. They are downloaded



automatically on first run via the Kaggle API (Lab 2, Lab 3.0) or generated



procedurally (Lab 1, Lab 3).
